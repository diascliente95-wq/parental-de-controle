Gerar aplicativo Android

Use a automação do GitHub para compilar os arquivos da pasta Android e gerar um APK de teste para baixar no celular.

Abrir gerador de APK no GitHub

Como gerar

  1. Entre na sua conta do GitHub.
  2. Na página da automação, toque em Run workflow e confirme.
  3. Espere a execução terminar com status verde.
  4. Abra a execução e procure Artifacts.
  5. Baixe guardiao-familia-debug-apk, extraia o ZIP e instale o APK no aparelho de teste.
Importante: este é um APK de depuração para testes, não uma versão assinada para publicar na Play Store. A primeira compilação pode falhar se o código precisar de ajustes; veja os registros da execução. O APK só fica disponível depois que a automação terminar com sucesso.
