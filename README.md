# Guardião Família — Controle Parental

Painel web responsivo para organizar a rotina digital em família.

## Recursos
- Perfil local da criança/adolescente.
- Limite diário de tela e registro manual de minutos.
- Rotinas com horários ajustáveis e ativação/desativação.
- Regras combinadas da família.
- Anotações e exportação dos dados em JSON.
- Layout adaptado a celulares e computadores.

## Como publicar com GitHub Pages
1. Abra Settings no repositório.
2. Entre em Pages.
3. Em Build and deployment, selecione Deploy from a branch.
4. Escolha a branch `main` e a pasta `/ (root)`, depois clique Save.
5. Aguarde a publicação e abra o endereço indicado na seção Pages.

## Limitações e privacidade
Este é um painel web demonstrativo. Os dados ficam no armazenamento local do navegador usado; não sincronizam automaticamente entre aparelhos. Não bloqueia aplicativos, não rastreia localização e não monitora o dispositivo em segundo plano. Para controle real do Android é necessário criar um aplicativo nativo, configurar permissões adequadas e dar consentimento no aparelho da criança. Use de forma transparente e adequada à idade.
